    Loading data

    Open the Files view (File, Add Data), then drop files on it or choose them with Add Files. Each file is read as one of these kinds, which you can change in its row:

    • Link list: a CSV or Excel sheet with a source, a target and, usually, a distance for each link.
    • Node list: a CSV or Excel sheet with one row per node, whose columns (dates, places, groups and so on) color and filter the views.
    • Distance matrix: a CSV of distances between every pair of nodes.
    • FASTA: sequences. MicrobeTrace computes the distances between them (the distance metric is in the Files settings), and can align them first.
    • Newick: a phylogenetic tree.
    • A saved MicrobeTrace session (.microbetrace): opens the whole session as it was saved.

    Press Launch to build the network. Where files disagree about a node, the file nearest the top wins; the Conflicts view lists the differences. To look around first, use Try the demo data on the Files view.

    The views

    The View menu opens each one. A view that needs data the session doesn't have says what it needs when it opens.

    • Network: nodes and links; color, size and filter them by any column.
    • Table: the nodes or links as rows. Aggregation, Crosstab, Bubbles, Histogram, Scatterplot and Flow Diagram: summaries of columns.
    • Sequences: the aligned sequences. Phylogenetic Tree and Heatmap: need sequences or a distance matrix (the tree can also come from a Newick file).
    • Map, Globe and Choropleth: need latitude and longitude, or country, state, county, zipcode or tract columns.
    • Timeline and Gantt: need a column of dates.
    • Waterfall: each cluster's links. Conflicts: where files disagree.

    Thresholds and links

    Nodes are linked when their distance is at or below the Link Threshold (in the global settings, with a sparkline of the distances you can click or drag). Lowering it keeps only closer links; raising it adds more. Clusters are the groups of nodes that are connected, so they change with the threshold. The link settings also choose which distance metric to use, and how to prune links.

    Saving, stashing and exporting

    • File, Save writes the whole session to a .microbetrace file you can open later (File, Open), or just its style. Nothing is sent anywhere.
    • Stash in Browser keeps a named copy in this browser, on this computer, and Recall from Browser brings it back. Clearing the browser's site data deletes stashes, so save a file for anything you need to keep. If automatic stashing is on, MicrobeTrace offers to restore the last session at startup.
    • Each view's download button exports what it shows: an image (PNG, JPEG, SVG), or for the tree a Newick file. The Table view exports its rows.

    Maps and tiles

    The map's boundaries and places come with MicrobeTrace and work offline. The background map layers (street, satellite and so on) are tiles downloaded from the Internet when you turn them on, so they show nothing without a connection. Draw nodes and links on a blank background, or with the country, state and county outlines, to stay offline.

    Mouse and keyboard shortcuts

    • Ctrl+F (⌘+F on a Mac): search nodes by ID.
    • Ctrl+S (⌘+S): save.
    • Network view, with the view focused: arrow keys move between nodes, N and P step through them, L follows links, Enter selects, G selects a node's neighbours (press again to take in the nodes one more link out), F pins, M opens the node menu, Esc clears, and ? lists the keys.

    About MicrobeTrace

    MicrobeTrace v

    MicrobeTrace is an interactive web application that renders existing data from high-risk contact networks in an easy-to-use Graphical User Interface (GUI). The network visualization can be customized according to supplemental data sources and mathematical inferences like the most probable transmission pathways. MicrobeTrace is a highly responsive, visual sequence analytics tool which can reduce the gap between data production and analytics and help you to discover, understand, and display relationships (links) between patients (nodes). MicrobeTrace can be deployed on laptops to locations without any Internet access, thereby reducing both the startup cost and analysis time and effort.

    Read the MicrobeTrace wiki

    MicrobeTrace was originally built by the Molecular Epidemiology and Bioinformatics Team at the US Centers for Disease Control and Prevention (CDC) in Atlanta. This copy is maintained independently at aaboyles.github.io/MicrobeTrace; CDC does not operate or endorse it. Report problems at GitHub Issues.

    Privacy

    • Your data stays in this browser. Files you load are processed on this computer and are never uploaded.
    • Stored on this computer: stashed sessions (and autostashes, if you turn Session Recovery on) are kept unencrypted in this browser's IndexedDB, with your accepted license. They include sequences and case attributes, last after the tab closes, and can be read by anyone using this browser profile. The app's offline copy is kept in the browser cache, and the WebMCP switch is remembered for the tab only.
    • Third parties: only when you turn on a map base layer, tiles are requested from CARTO (street map) or Esri (satellite), who can see your IP address and the area you view. Nothing else is sent anywhere, and there is no analytics or tracking.
    • AI agents: if you switch on WebMCP, agents in this browser can read and change the whole session, including its data. It is off by default and lasts for this tab only.

    Delete everything stored in this browser?

    This permanently deletes all stashed and autostashed sessions, your accepted license and the offline copy of MicrobeTrace kept by this browser, then reloads the page. Unsaved work in this tab will be lost. This cannot be undone.

    Start a new session?

    Your data and settings will be cleared. Save them first to come back to them.

    Replace the current session?

    Unsaved changes will be lost. Stash the current session first to come back to it.

    Restore your previous session?

    MicrobeTrace found a recovery copy of a session saved in this browser on . It may be there because the last session ended unexpectedly. Discarding it deletes it from this browser.
