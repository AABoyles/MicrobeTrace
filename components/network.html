Arrow keys move to the nearest node in that direction, N and P step through every node, L follows the focused node's links, Enter selects, G selects the node's neighbours (again: nodes further out), C selects the node's cluster, A selects every node, F pins, M opens the node menu, Escape clears the selection, and question mark lists the keys. The Table view lists the same nodes.

F

M, Shift+F10
