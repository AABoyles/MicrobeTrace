# Security Policy

MicrobeTrace began at the US Centers for Disease Control and Prevention (CDC). This copy, at
https://aaboyles.github.io/MicrobeTrace/ and https://github.com/AABoyles/MicrobeTrace, is maintained
independently. CDC does not operate, support or endorse it, so please do not send reports about it to CDC.

## Reporting a Vulnerability

If you discover a vulnerability in this version of MicrobeTrace, please 
[file a security advisory](https://github.com/aaboyles/MicrobeTrace/security/advisories)
or detail it in an email to aaboyles@gmail.com. Please **do not** file an
issue report on Github. We'll get back to you as soon as we've attempted to verify the
vulnerability you're reporting. If your report is confirmed, we'll write and release a patch as quickly as we possibly can.
