# Security Policy

This is the Historical project from which CDC's MicrobeTrace has evolved. It is NOT supported by CDC. Development directions
between the CDC's version and this on have diverged, and changes to this fork will not be merged to the CDC version.

If you require the CDC's version of MicrobeTrace, please go to:

* https://microbetrace.cdc.gov/MicrobeTrace for the application, or
* https://github.com/CDCgov/MicrobeTrace for the code.

## Reporting a Vulnerability

If you discover a vulnerability in this version of MicrobeTrace, please 
[file a security advisory](https://github.com/aaboyles/MicrobeTrace/security/advisories)
or detail it in an email to aaboyles@gmail.com. Please **do not** file an
issue report on Github. We'll get back to you as soon as we've attempted to verify the
vulnerability you're reporting. If your report is confirmed, we'll write and release a patch as quickly as we possibly can.
